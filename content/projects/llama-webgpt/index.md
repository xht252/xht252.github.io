Llama WebGPT is a web application that provides an interactive frontend for a fine-tuned LLaMA large language model.

The project combines a Flask backend with a frontend developed using Vue, JavaScript, and CSS.

## Main Components

- Flask-based web backend
- Vue and JavaScript frontend
- CSS-based interface design
- Integration with a fine-tuned LLaMA model
